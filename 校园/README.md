# 青柠校园 · 校园社区

一个可本地运行的前后端校园论坛示例。

## 技术栈
- 前端：Vue 3 + Vite
- 后端：Node.js + Express
- 数据库：SQLite（better-sqlite3）
- 登录：bcryptjs 密码哈希 + express-session + SQLite session store

## 环境要求
- Node.js 20 LTS 或更新的 LTS 版本
- npm

## 启动
在项目根目录打开终端，运行：

```bash
npm install
npm run dev
```

然后打开：
- 前端页面：http://127.0.0.1:5173
- 后端健康检查：http://127.0.0.1:3000/api/health

首次启动会在 `server/data/` 创建 SQLite 数据库并插入演示帖子。数据库文件不应上传到公共代码仓库。

## 功能
- 注册、登录、退出登录；服务端使用 bcrypt 哈希密码
- SQLite 持久化用户、帖子、评论、点赞与登录 session
- 发布、搜索、分类筛选帖子
- 点赞 / 取消点赞
- 评论、删除自己的评论
- 删除自己的帖子
- 修改个人简介
- 手机端响应式布局

## 生产部署前必须处理
1. 设置强随机 `SESSION_SECRET` 环境变量，不要使用代码中的开发默认值。
2. 使用 HTTPS，并设置 `NODE_ENV=production`。
3. 增加 CSRF 防护、内容审核、举报/封禁、备份和日志策略。
4. 配置账号验证、密码重置、隐私政策与数据删除流程。
5. 生产环境建议使用反向代理，并根据访问量评估 PostgreSQL 等服务端数据库。
6. Google Fonts 只用于可选字体美化；没有网络时会回退到系统字体。
7. 当前使用本机回环地址绑定，适合本地开发。若要让其他设备访问，需调整监听地址、代理和防火墙设置，并进行安全配置。
